# 对话地图 · 交互演示页

一个零依赖的单文件网页，用来在浏览器里直接演示 dsh-talk-map 插件的面板功能——不需要安装 DSH 或重启宿主。

## 打开方式

直接双击 `index.html`（或拖进 Edge）。无构建、无依赖、无网络请求。

## 覆盖的面板功能

| 插件功能 | 演示页操作 |
|---|---|
| 无限画布平移/缩放 | 空白处拖动平移；滚轮缩放（以光标为中心） |
| 工作区框架 | 4 个预置工作区（日常任务 / Open MedKit / 实验场 / 实习），框架可整体拖动 |
| 卡片 | 11 张，含标题/正文/相对时间，可拖动摆放 |
| 状态灯牌 | 运行中（白光环 + conic 流光）/ 待查看绿 / 异常红 / 等待黄，全部带呼吸动画 |
| 堆叠抽屉 | 工作区标题旁的黄色徽标（≥5 张卡出现），点开抽屉，抽屉内可搜索过滤 |
| 全局搜索 | 顶部搜索框输入 + 回车，命中高亮，点击结果画布飞到该卡片 |
| 连线 | 从卡片**左/右边缘**按住拖到另一张卡片松手；同一套规则（太近自动从上下边绕行）；同步后的线隐藏 |
| 右键菜单 | 卡片：打开/置顶/重命名/标未读/摘要/归档/删除；连线：开启自动推送/删除连线；空白：新建对话/新建工作区 |
| 双击空白 | 原地新建对话（落在所在工作区网格里） |
| 字号 A−/A+/默认 | 顶部按钮，同插件行为 |

## 数据

演示数据内嵌在 `index.html` 顶部的 `DATA` 对象里（4 工作区 / 11 卡片 / 2 条边），改它就能换演示内容。

## 说明

- 演示页是**纯前端模拟**，交互结果（打开对话、归档等）用 toast 提示代替真实动作；
- 视觉 tokens（颜色、圆角、点阵网格、灯牌动画、连线样式）与插件样式表一致，但不是同一份代码；
- 真实插件以 `D:\Plugins\dsh-talk-map` 的 client bundle 为准。
